# Release Roadmap

We are committed to open-sourcing the full implementation and pretrained weights.

- [ ] Release **inference** code
- [ ] Release **training** code (teacher–student distillation)
- [ ] Release **pretrained weights** (student; and teacher as applicable)
- [ ] Release **preprocessing & teacher feature extraction** scripts
- [ ] Release evaluation scripts (Dice / HD95, 15-combination protocol)

## Notes on timing

- Files are released **once the code is ready**.
- The exact license will be confirmed at the time of release.
- Any updates will be announced in this repository (watch / star to stay notified).
