# Contributing

Thanks for your interest in MLKTNet!

At this stage the repository only contains documentation (the code is not released yet).
We nonetheless welcome:

- **Bug reports / questions** about the method or the documented protocols — please open an issue.
- **Reproducibility feedback** — if anything in `docs/` is unclear or insufficient to reproduce
  the setup, tell us via an issue so we can improve it before the code release.

Once the code is released, contribution guidelines (branching, style, tests, and pull-request
workflow) will be added here.

Please be respectful and constructive in all interactions.
